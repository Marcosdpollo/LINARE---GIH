# Guia de imagens — Linare

Este guia mostra **exatamente** o nome e a pasta que cada foto precisa ter para aparecer automaticamente no site. Basta seguir essa estrutura de pastas no seu repositório do GitHub, ao lado do arquivo index.html:

```
index.html
assets/
  produtos/
  categorias/
  hero/
  portfolio/
```

Enquanto uma foto não existir, o site mostra automaticamente o ícone ilustrativo no lugar — nada quebra. Assim que você subir a foto com o nome certo, ela substitui o ícone sozinha, sem precisar mexer em nenhum código.

## Dicas rápidas
- Os nomes são case-sensitive no GitHub: use sempre letras minúsculas e hífen, exatamente como na tabela.
- Pode subir aos poucos — o produto que ainda não tiver foto continua mostrando o ícone normalmente.
- Quando os mockups estiverem prontos, é só arrastar os arquivos .jpg com esses nomes para as pastas certas no GitHub (ou pelo Desktop do GitHub) — não precisa editar o index.html.
